# 🎵 Ayu Music

Музыка, персональные волны и своя медиатека внутри **exteraGram / AyuGram**.

Ayu Music помогает находить песни, открывать новых исполнителей и собирать плейлисты. Воспроизведение работает через штатный плеер Telegram.

**Версия:** 1.4.0 · **Автор:** [@Demon_In_Moscow](https://t.me/Demon_In_Moscow)

## Что нового в 1.4.0

- **Автоочистка временного аудио.** После окончания песни или переключения на другую её временные файлы удаляются из кэша Telegram. Очистка учитывает незавершённые загрузки и предзагрузку следующего трека.
- **Сохранение по выбору.** Чтобы оставить песню для прослушивания без интернета, выберите «Скачать в кэш» или «Сохранить в кэш» в меню трека. Лайк и добавление в плейлист сохраняют запись о песне, но не закрепляют аудиофайл.
- **Все найденные локальные треки во вкладке «Кэш».** В ней отображаются доступные на устройстве файлы известных плагину треков, включая музыку, скачанную через Telegram, и доступные исходные локальные файлы.
- **Защита нужных файлов.** Пауза и повтор одной песни сохраняют текущий файл. Явно сохранённые треки и исходные локальные файлы защищены от автоочистки.

## Возможности

- **Моя волна** — подбор по исполнителям, жанрам, лайкам, прослушиваниям и пропускам.
- **Волна по треку** — новые песни в направлении выбранной композиции.
- **Волна по плейлисту и всему «Любимому»** — учитывается вся коллекция, включая треки за пределами видимой страницы.
- **Встряхнуть волну** — обновить подборку, сохранив её основу.
- **Поиск музыки** через музыкальный источник, настроенный в клиенте Telegram.
- **Локальные лайки и плейлисты**, импорт аудиозаписей из чатов.
- **Скачивание в кэш Telegram** для прослушивания сохранённых файлов без интернета.
- **Автоочистка временных файлов прослушивания** и общий список найденных локальных треков во вкладке «Кэш».
- **Настройка оформления:** темы, цвета блоков, шрифты и анимированный фон с цветами по жанрам.
- **Мини-плеер с меню текущей песни**, открытие штатного плеера, резервная копия коллекции и диагностика.

Рекомендации строятся по исполнителям, локальному каталогу жанров и действиям внутри плагина. Звучание аудиофайлов не анализируется. Для неизвестного исполнителя можно выбрать направление вручную.

## Требования

- exteraGram **13.1.1+** или совместимая сборка AyuGram с системой плагинов exteraGram.
- Включённая система плагинов и Python SDK **1.4.4.3+** в клиенте.

## Установка

1. Скачайте [ayu_music.plugin](./ayu_music.plugin?raw=1).
2. Отправьте файл себе в Telegram и откройте его в совместимом клиенте.
3. Подтвердите установку и включите плагин.
4. Откройте Ayu Music через значок музыки в верхней панели списка чатов.

## С чего начать

| Что хотите включить | Где найти |
| --- | --- |
| Мою волну | Главная → «Настроить волну» → выберите исполнителей и жанры → запуск |
| Волну по песне | ⋮ у трека или в мини-плеере → «Волна по треку» |
| Волну по плейлисту | Откройте плейлист → «Волна по всему плейлисту» |
| Волну по любимому | Медиатека → «Треки» → «Волна по всему любимому» |
| Скачать песню | ⋮ у трека → «Скачать в кэш» |
| Сохранить уже загруженную временную песню | ⋮ у трека → «Сохранить в кэш» |
| Найти локальные треки | Медиатека → «Кэш» |
| Импортировать музыку | Меню чата → «Импорт музыки в Ayu Music» или меню аудиосообщения → «В плейлист Ayu Music» |

## О коллекции и кэше

- Лайки, плейлисты и предпочтения хранятся на устройстве отдельно для каждого аккаунта.
- **«Любимое» Ayu Music, «Избранное» Telegram и музыка профиля — отдельные коллекции.** Сердечко в плагине добавляет песню в его собственное «Любимое».
- **Лайк и плейлист сохраняют сведения о песне.** Для постоянного хранения её аудиофайла используйте «Скачать в кэш» или «Сохранить в кэш» в меню трека. Скачивание целого плейлиста также считается явным сохранением.
- **Обычное прослушивание использует временные файлы.** После окончания или переключения песни плагин очищает их. Текущая песня на паузе, повтор одного трека и нужная предзагрузка следующей песни защищены от преждевременной очистки.
- **Вкладка «Кэш» показывает найденные файлы известных плагину треков**, в том числе скачанные через Telegram и доступные исходные локальные файлы. Само появление временной песни в этой вкладке не закрепляет её для постоянного хранения.
- Явно сохранённые треки и исходные локальные файлы защищены от автоочистки. Незавершённые загрузки, выбранные для сохранения, остаются в очереди.
- Очистка медиакэша Telegram удаляет скачанные файлы. Записи о любимых песнях и плейлистах плагина сохраняются.
- Повторное скачивание импортированной музыки зависит от доступности исходного сообщения.
- Резервную копию лайков, плейлистов и интересов можно скопировать из настроек плагина. Аудиофайлы в неё не входят.
